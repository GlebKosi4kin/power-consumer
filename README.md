# power-consumer
Сервис для сбора и анализа данных о расходе энергии на производственных линиях. Приложение получает телеметрию с IoT-счетчиков по протоколу MQTT, сохраняет её в БД и рассчитывает средний, пиковый и удельный расход на единицу продукции. На основе данных генерируются интерактивные дашборды с графиками и рекомендации по снижению энергопотребления.
