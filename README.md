# Мониторинг энергопотребления

Проект визуализирует почасовое потребление электроэнергии промышленного объекта, выявляет аномалии и формирует рекомендации. Данные генерируются по реалистичному профилю завода за период с 1 января по 1 февраля 2026 года — 744 записи, по одной на каждый час.

## Архитектура

Проект разворачивается в пяти Docker-контейнерах. Postgres хранит почасовые показания, Mosquitto выступает брокером сообщений, Python-генератор наполняет базу и публикует данные в MQTT, бэкенд на Scala / Play Framework обслуживает REST API и подписывается на топики, Nginx раздаёт статический дашборд.

## Запуск
Для Windows: сначала запускаам генератор с корня проекта, 
можно хоть в Pycharm. Включаем Docker, разворачиваем проект
командой docker-compose up -d --build из папки с проектом!

```bash
Linux:
make up        # собрать образы, запустить, наполнить БД
make down      # остановить контейнеры
make generate  # повторно запустить генератор
make logs      # логи всех контейнеров
make clean     # полный сброс — удалить контейнеры и тома
make status    # статус контейнеров
```

После `make up` сервисы доступны по адресам:

| Сервис   | Адрес                    |
|----------|--------------------------|
| Фронт    | http://localhost         |
| API      | http://localhost:9000/api |
| MQTT     | localhost:1883           |
| Postgres | localhost:5432           |

## Профиль потребления

Генератор создаёт данные по четырём временным периодам суток:

| Период     | Часы  | Диапазон     | Порог аномалии |
|------------|-------|--------------|----------------|
| T1_NIGHT   | 00–05 | 5–10 МВт·ч   | > 12 МВт·ч     |
| T2_MORNING | 06–09 | 10–22 МВт·ч  | > 25 МВт·ч     |
| T3_DAY     | 10–18 | 22–27 МВт·ч  | > 30 МВт·ч     |
| T2_EVENING | 19–23 | 20→10 МВт·ч  | > 23 МВт·ч     |

Около 4% часов получают аномальное значение. При превышении порога в базу автоматически сохраняется рекомендация, специфичная для периода суток.

## API

```
GET /api/readings?date=YYYY-MM-DD
GET /api/readings/range?from=&to=
GET /api/anomalies?from=&to=
GET /api/stats/daily?date=YYYY-MM-DD
GET /api/stats/monthly?year=YYYY&month=M
```

## Схема базы данных

Таблица `energy_readings`:

| Поле              | Тип            | Описание                              |
|-------------------|----------------|---------------------------------------|
| id                | SERIAL PK      |                                       |
| date              | DATE           | Дата записи                           |
| hour              | INTEGER (0–23) | Час суток                             |
| consumption_mwh   | DECIMAL(10,2)  | Потребление в МВт·ч                   |
| period            | VARCHAR(20)    | T1_NIGHT / T2_MORNING / T3_DAY / T2_EVENING |
| is_anomaly        | BOOLEAN        | Признак аномалии                      |
| recommendation    | TEXT           | Автоматическая рекомендация           |
| created_at        | TIMESTAMP      | Время создания записи                 |
